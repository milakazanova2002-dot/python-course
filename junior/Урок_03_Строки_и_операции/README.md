## 1. Строки: напоминание и новые приёмы

**Строка** (`str`) это текст. Её можно записывать в двойных или одинарных кавычках, разницы нет:

```python
print("Привет")
print('Привет')
```

Если внутри текста нужна кавычка, возьми для строки другой вид кавычек:

```python
print("Это 'цитата' внутри текста")
print('А это "цитата" внутри текста')
```

### Специальные символы

Внутри строки можно писать специальные символы, которые начинаются с обратной косой черты `\`:

| Запись | Что делает |
|---|---|
| `\n` | переход на новую строку |
| `\t` | табуляция (большой пробел) |

```python
print("Первая строка\nВторая строка")
print("Имя:\tАня")
```

```
Первая строка
Вторая строка
Имя:	Аня
```

### Склейка и повтор (из прошлого урока)

```python
print("Привет, " + "Аня")
print("Ха" * 3)
```

Склеивать через `+` можно **только строки со строками**. Число придётся превращать через `str()`. Это неудобно, поэтому есть способ лучше.

## 2. f-строки

**f-строка** позволяет вставлять значения переменных прямо внутрь текста. Перед открывающей кавычкой пишется буква `f`, а переменные заключаются в фигурные скобки `{}`.

```python
name = "Аня"
age = 14
print(f"Меня зовут {name}, мне {age} лет")
```

```
Меня зовут Аня, мне 14 лет
```

Сравни с тем, как пришлось бы писать без f-строки:

```python
print("Меня зовут " + name + ", мне " + str(age) + " лет")
```

С f-строкой короче, и не нужно превращать число в строку.

Правила:

- буква `f` стоит **перед кавычкой**, без пробела: `f"..."`;
- внутри `{}` пишется имя переменной;
- без буквы `f` фигурные скобки не сработают: `"Привет, {name}"` выведет текст вместе со скобками.

### Выражения внутри скобок

Внутри `{}` можно писать не только имя переменной, но и вычисления:

```python
a = 7
b = 3
print(f"{a} + {b} = {a + b}")
print(f"{a} * {b} = {a * b}")
```

```
7 + 3 = 10
7 * 3 = 21
```

### Округление в f-строке

Результат деления часто получается с длинным хвостом:

```python
print(10 / 3)
```

```
3.3333333333333335
```

Чтобы оставить, например, два знака после точки, после значения ставят двоеточие и `.2f`:

```python
result = 10 / 3
print(f"{result:.2f}")
```

```
3.33
```

Читается так: `.2f` значит «дробное число с двумя знаками после точки». Цифру `2` можно менять: `.1f` даст один знак, `.3f` три.

## 3. Длина строки: len()

Функция `len()` возвращает, сколько символов в строке. Пробелы и знаки тоже считаются.

```python
word = "Python"
print(len(word))
print(len("Привет, мир"))
```

```
6
11
```

`len()` возвращает целое число, поэтому его можно использовать в вычислениях:

```python
name = input("Как тебя зовут? ")
print(f"В твоём имени {len(name)} букв")
```

## 4. Индексы: доступ к отдельным буквам

Каждый символ строки имеет свой номер, он называется **индексом**. Важно: **нумерация начинается с нуля**.

```
 П  р  и  в  е  т
 0  1  2  3  4  5
```

Чтобы достать символ, пишут имя строки и номер в квадратных скобках:

```python
word = "Привет"
print(word[0])
print(word[2])
```

```
П
и
```

Индексы можно считать и **с конца**: последний символ имеет номер `-1`, предпоследний `-2` и так далее.

```
 П   р   и   в   е   т
-6  -5  -4  -3  -2  -1
```

```python
print(word[-1])
print(word[-2])
```

```
т
е
```

Последний символ удобно получать так: `word[-1]`, не думая о длине.

### Ошибка IndexError

Если взять номер, которого нет, получится ошибка:

```python
word = "Привет"
print(word[10])
```

```
IndexError: string index out of range
```

В слове шесть букв, индексы от `0` до `5`, а `10` слишком много.

## 5. Срезы

**Срез** достаёт не один символ, а кусок строки. Записывается так: `строка[от:до]`. Символ с номером «от» **входит** в срез, а символ с номером «до» **не входит**.

```python
word = "Привет"
print(word[0:3])
print(word[2:5])
```

```
При
иве
```

Разбор `word[0:3]`: берём символы с номерами `0`, `1`, `2`, а `3` уже не берём.

Если «от» или «до» не указать, Python возьмёт начало или конец строки:

```python
print(word[:3])    # от начала до 3-го (не включая)
print(word[2:])    # от 2-го до конца
print(word[:])     # всё слово
```

```
При
ивет
Привет
```

### Срез с шагом

Можно добавить третье число, **шаг**: `строка[от:до:шаг]`.

```python
word = "Привет"
print(word[::2])
```

```
Пие
```

Берётся каждый второй символ. А если шаг равен `-1`, строка читается задом наперёд:

```python
print(word[::-1])
```

```
тевирП
```

## 6. Строки нельзя менять «на месте»

Строки **неизменяемы**: изменить одну букву внутри уже созданной строки нельзя.

```python
word = "Привет"
word[0] = "п"
```

```
TypeError: 'str' object does not support item assignment
```

Если нужна новая строка, её создают заново, например, склейкой и срезами:

```python
word = "Привет"
word = "п" + word[1:]
print(word)
```

```
привет
```

> Запомни слово «неизменяемый». Оно нам ещё пригодится: когда мы будем изучать списки, то увидим тип данных, который *можно* менять на месте.

## 7. Методы строк

У строк есть готовые «умения», которые называются **методами**. Метод вызывается через точку после строки:

```python
text = "python"
print(text.upper())
```

```
PYTHON
```

Запись `text.upper()` значит: «для строки `text` вызови метод `upper`». Скобки нужны всегда, даже если внутри пусто.

### Главные методы

| Метод | Что делает | Пример | Результат |
|---|---|---|---|
| `upper()` | все буквы заглавные | `"abc".upper()` | `"ABC"` |
| `lower()` | все буквы маленькие | `"ABC".lower()` | `"abc"` |
| `capitalize()` | первая буква заглавная, остальные маленькие | `"пРИВЕТ".capitalize()` | `"Привет"` |
| `title()` | каждое слово с заглавной буквы | `"иван иванов".title()` | `"Иван Иванов"` |
| `strip()` | убирает пробелы по краям | `"  hi  ".strip()` | `"hi"` |
| `replace(старое, новое)` | заменяет часть строки | `"a-b".replace("-", "+")` | `"a+b"` |
| `count(часть)` | считает, сколько раз часть встречается | `"banana".count("a")` | `3` |
| `find(часть)` | индекс первого вхождения, или `-1`, если нет | `"banana".find("n")` | `2` |

### Методы не меняют исходную строку

Это важно. Метод **возвращает новую строку**, а старая остаётся как была:

```python
name = "аня"
name.upper()
print(name)
```

```
аня
```

Ничего не изменилось, потому что результат нигде не сохранён. Чтобы сохранить, нужно записать результат в переменную:

```python
name = "аня"
name = name.upper()
print(name)
```

```
АНЯ
```

Или сразу вывести:

```python
print(name.upper())
```

### Пример: исправляем ввод пользователя

Пользователи вводят имена как попало. Метод `title()` наводит порядок:

```python
name = input("Как тебя зовут? ")
name = name.strip().title()
print(f"Привет, {name}!")
```

```
Как тебя зовут?   иВАН  
Привет, Иван!
```

Методы можно соединять в цепочку: сначала `strip()` убирает пробелы, потом `title()` исправляет регистр.

## 8. Проверка: есть ли часть внутри строки

Слово `in` проверяет, содержится ли одна строка в другой. Результат это значение типа `bool`: `True` или `False`.

```python
text = "Я учу Python"
print("Python" in text)
print("Java" in text)
```

```
True
False
```

Слова `not in` проверяют обратное:

```python
print("Java" not in text)
```

```
True
```

> Пока мы просто выводим результат на экран. В уроке 4 мы научимся использовать такие проверки, чтобы программа сама принимала решения.

## 9. Полезные функции для чисел

| Функция | Что делает | Пример | Результат |
|---|---|---|---|
| `round(число)` | округляет до целого | `round(3.7)` | `4` |
| `round(число, n)` | округляет до `n` знаков | `round(3.14159, 2)` | `3.14` |
| `abs(число)` | модуль числа (убирает минус) | `abs(-5)` | `5` |
| `min(a, b, ...)` | наименьшее | `min(4, 9, 2)` | `2` |
| `max(a, b, ...)` | наибольшее | `max(4, 9, 2)` | `9` |

```python
a = float(input("Первое число: "))
b = float(input("Второе число: "))
print(f"Среднее: {round((a + b) / 2, 2)}")
```

> `round()` меняет само число, а `:.2f` в f-строке меняет только то, как оно показано на экране.

## 10. Частые ошибки

| Ошибка | Что значит | Как исправить |
|---|---|---|
| Вместо значения в тексте выводится `{name}` | Забыли букву `f` перед кавычкой | Напиши `f"..."` |
| `IndexError: string index out of range` | Взяли индекс больше, чем есть символов | Помни, что нумерация идёт с `0` и последний индекс на единицу меньше длины |
| `TypeError: 'str' object does not support item assignment` | Пытаешься поменять букву в строке на месте | Создай новую строку |
| После `name.upper()` имя не изменилось | Результат метода нигде не сохранён | `name = name.upper()` |
| `AttributeError: 'str' object has no attribute 'Upper'` | Метод написан с ошибкой (регистр!) | Все методы пишутся маленькими буквами: `upper()` |

## Итоги урока

- **f-строка** (`f"Привет, {name}"`) вставляет значения в текст. Округление: `{число:.2f}`.
- `len(s)` возвращает длину строки.
- **Индекс** это номер символа. Нумерация с нуля, с конца `-1`, `-2`, ...
- **Срез** `s[от:до]` достаёт кусок строки (конец не входит). Шаг `-1` читает строку задом наперёд.
- Строки **неизменяемы**. Методы возвращают **новую** строку.
- Методы: `upper`, `lower`, `capitalize`, `title`, `strip`, `replace`, `count`, `find`.
- `"a" in s` проверяет, есть ли часть в строке, и возвращает `True` или `False`.
- `round()`, `abs()`, `min()`, `max()` помогают в вычислениях.

**Задание 15.** Спроси у пользователя слово и выведи его задом наперёд. Потом выведи, является ли слово **палиндромом** (читается одинаково в обе стороны, как «шалаш»), в виде `True` или `False`.

<summary>Подсказка</summary>
