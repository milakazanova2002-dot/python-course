# Урок 2. Переменные и типы данных

**Цель урока:** научиться хранить данные в переменных, понимать, чем отличаются типы данных, и получать данные от пользователя с помощью `input()`.

**К концу урока ты умеешь:**
- создавать переменные и менять их значения;
- давать переменным правильные имена;
- отличать `int`, `float`, `str` и `bool`;
- считать с помощью арифметических операций;
- спрашивать у пользователя данные через `input()`;
- преобразовывать один тип в другой.

---

## 1. Что такое переменная

Программа работает с данными: именами, возрастами, ценами, очками в игре. Эти данные нужно где-то хранить. Для этого есть **переменные**.

**Переменная** это имя, под которым в памяти компьютера хранится значение. Её можно представить как коробку с подписью: на коробке написано имя, а внутри лежит значение.

```python
name = "Аня"
age = 14
```

```
name = "Аня"
 ↑      ↑
имя   значение
```

Знак `=` в Python означает не «равно», а **«положить в переменную»**. Читается справа налево: «возьми значение `"Аня"` и положи в переменную `name`».

Теперь переменную можно использовать вместо значения:

```python
name = "Аня"
age = 14
print(name)
print(age)
print(name, age)
```

```
Аня
14
Аня 14
```

> Обрати внимание: `print(name)` без кавычек выводит **значение переменной**, а `print("name")` с кавычками выводит слово `name`.

### Значение можно менять

```python
score = 0
print(score)

score = 10
print(score)
```

```
0
10
```

Новое значение заменяет старое. Старое пропадает.

Значение можно считать через само себя:

```python
score = 10
score = score + 5
print(score)
```

```
15
```

Разберём строку `score = score + 5`. Сначала Python считает правую часть: берёт текущее значение `score` (это `10`) и прибавляет `5`. Получается `15`. Затем кладёт `15` обратно в `score`.

### Несколько переменных

Переменные можно создавать сколько угодно и считать с ними:

```python
a = 7
b = 3
c = a + b
print(c)
```

## 2. Как называть переменные

Правила, которые **обязательны** (иначе будет ошибка):

- имя состоит из букв, цифр и знака подчёркивания `_`;
- имя **не может начинаться с цифры** (`1name` нельзя, `name1` можно);
- в имени **нет пробелов** и других символов (`-`, `!`, `$` и т. д.);
- нельзя использовать служебные слова Python (`if`, `for`, `while`, `print` и другие).

Правила, которые **желательны** (так принято у программистов):

- имя должно объяснять, что внутри: `age` лучше, чем `a`, а `player_score` лучше, чем `x`;
- пиши маленькими буквами, а слова разделяй подчёркиванием: `player_name`, `total_price`. Такой стиль называется *snake_case*;
- пиши имена латиницей.

**Важно:** Python различает большие и маленькие буквы. `name`, `Name` и `NAME` это три разные переменные.

| Имя | Можно? |
|---|---|
| `age` | да |
| `my_age` | да |
| `age2` | да |
| `2age` | нет, начинается с цифры |
| `my age` | нет, пробел |
| `my-age` | нет, дефис |
| `for` | нет, служебное слово |

## 3. Типы данных

Данные бывают разных видов. Вид данных называется **типом**. Python по-разному обращается с числами и с текстом, поэтому тип важен.

Четыре основных типа:

| Тип | Название | Что хранит | Примеры |
|---|---|---|---|
| `int` | целое число | числа без дробной части | `5`, `-12`, `0`, `2026` |
| `float` | дробное число | числа с дробной частью | `3.14`, `-0.5`, `2.0` |
| `str` | строка | текст | `"Привет"`, `'abc'`, `"123"` |
| `bool` | логический | только два значения: правда или ложь | `True`, `False` |

Несколько важных замечаний:

- Дробная часть в Python отделяется **точкой**, а не запятой: `3.14`, а не `3,14`.
- Всё, что в кавычках, это строка, даже если внутри цифры. `"123"` это текст, а не число.
- `True` и `False` пишутся **с большой буквы** и без кавычек.

### Как узнать тип: type()

Функция `type()` показывает, какого типа значение:

```python
print(type(5))
print(type(3.14))
print(type("Привет"))
print(type(True))
```

```
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

То же самое работает и с переменными:

```python
age = 14
print(type(age))
```

```
<class 'int'>
```

### Число и текст: в чём разница

Сравни:

```python
print(5 + 5)
print("5" + "5")
```

```
10
55
```

Числа Python **складывает**, а строки **склеивает**. Склейка строк называется *конкатенацией*.

Строку можно умножить на число, тогда она повторится:

```python
print("Ха" * 3)
```

```
ХаХаХа
```

## 4. Арифметика

В Python есть такие операции:

| Операция | Знак | Пример | Результат |
|---|---|---|---|
| Сложение | `+` | `7 + 2` | `9` |
| Вычитание | `-` | `7 - 2` | `5` |
| Умножение | `*` | `7 * 2` | `14` |
| Деление | `/` | `7 / 2` | `3.5` |
| Целочисленное деление | `//` | `7 // 2` | `3` |
| Остаток от деления | `%` | `7 % 2` | `1` |
| Возведение в степень | `**` | `7 ** 2` | `49` |

Что нужно запомнить:

- **Обычное деление `/` всегда даёт `float`**, даже если делится нацело: `10 / 2` будет `5.0`.
- **`//`** отбрасывает дробную часть: сколько раз одно число *целиком* помещается в другое. `7 // 2` это `3`, потому что в семи помещается три двойки.
- **`%`** показывает, что осталось: `7 % 2` это `1`, потому что после трёх двоек остаётся единица.
- Порядок действий как в математике: сначала `**`, потом `*`, `/`, `//`, `%`, потом `+`, `-`. Скобки меняют порядок: `(2 + 3) * 4` даёт `20`.

> Зачем нужен `%`: например, чтобы проверить, чётное ли число. Если `n % 2` равно `0`, число чётное. А `//` и `%` вместе помогают перевести, скажем, 130 минут в часы и минуты: `130 // 60` это `2` часа, `130 % 60` это `10` минут.

### Сокращённая запись

Вместо `score = score + 5` можно писать короче:

```python
score = 10
score += 5
print(score)
```

```
15
```

Так же работают `-=`, `*=`, `/=`.

## 5. Ввод данных: input()

Пока что все данные мы записывали прямо в код. Но программы должны уметь **спрашивать** у пользователя. Для этого есть функция `input()`.

```python
name = input()
print("Привет,", name)
```

Когда программа доходит до `input()`, она **останавливается и ждёт**, пока пользователь что-то напечатает и нажмёт **Enter**. Введённый текст кладётся в переменную.

Чтобы пользователь понимал, что от него хотят, внутрь `input()` пишут подсказку:

```python
name = input("Как тебя зовут? ")
print("Привет,", name)
```

```
Как тебя зовут? Аня
Привет, Аня
```

(`Аня` здесь вводит пользователь.)

### Главная особенность input()

**`input()` всегда возвращает строку (`str`)**, даже если пользователь ввёл цифры.

```python
age = input("Сколько тебе лет? ")
print(type(age))
```

```
Сколько тебе лет? 14
<class 'str'>
```

Хотя мы ввели `14`, в переменной лежит строка `"14"`, а не число. Из-за этого возникает самая частая ошибка новичков:

```python
a = input("Первое число: ")
b = input("Второе число: ")
print(a + b)
```

```
Первое число: 3
Второе число: 4
34
```

Вместо `7` получилось `34`: Python склеил две строки. Чтобы он считал, нужно превратить строки в числа.

## 6. Преобразование типов

Для превращения одного типа в другой есть функции с теми же именами, что и типы:

| Функция | Что делает | Пример | Результат |
|---|---|---|---|
| `int()` | превращает в целое число | `int("14")` | `14` |
| `float()` | превращает в дробное число | `float("3.5")` | `3.5` |
| `str()` | превращает в строку | `str(14)` | `"14"` |

Теперь исправим программу с сложением:

```python
a = int(input("Первое число: "))
b = int(input("Второе число: "))
print(a + b)
```

```
Первое число: 3
Второе число: 4
7
```

Запись `int(input(...))` читается изнутри наружу: сначала `input()` получает текст, затем `int()` превращает его в число.

Для дробных чисел используй `float()`:

```python
price = float(input("Цена: "))
print(price * 2)
```

### Когда нужен str()

Строку и число нельзя склеивать через `+`:

```python
age = 14
print("Мне " + age + " лет")
```

```
TypeError: can only concatenate str (not "int") to str
```

Это можно исправить двумя способами:

```python
age = 14
print("Мне " + str(age) + " лет")   # превращаем число в строку
print("Мне", age, "лет")             # или используем запятые в print
```

Второй способ проще, пока мы не изучили f-строки (они будут в следующем уроке).

### Преобразование может не получиться

```python
number = int("abc")
```

```
ValueError: invalid literal for int() with base 10: 'abc'
```

Python не может превратить слово в число. Эта ошибка называется `ValueError`. Также `int("3.5")` вызовет ошибку: сначала нужно `float("3.5")`, а потом `int()`. Заметь, что `int(3.9)` даёт `3`: дробная часть просто отбрасывается, без округления.

---

## 7. Частые ошибки

| Ошибка | Что значит | Как исправить |
|---|---|---|
| `NameError: name 'x' is not defined` | Используешь переменную, которую не создал (или опечатка в имени, или другой регистр) | Проверь, что переменная создана выше и имя написано верно |
| `TypeError: can only concatenate str (not "int") to str` | Пытаешься склеить текст и число | Используй `str()` или запятые в `print` |
| `TypeError: unsupported operand type(s)` | Действие невозможно для таких типов, например `"5" - 2` | Преврати строку в число через `int()` |
| `ValueError: invalid literal for int()` | В `int()` попала не-число (буквы, пустая строка) | Проверь, что вводишь число |

---

## Итоги урока

- **Переменная** хранит значение под именем. Знак `=` кладёт значение в переменную.
- Имя: буквы, цифры, `_`, не начинается с цифры, регистр важен. Давай понятные имена.
- Типы: `int` (целые), `float` (дробные), `str` (текст), `bool` (`True`/`False`). Узнать тип: `type()`.
- Арифметика: `+ - * / // % **`. Обычное деление `/` всегда даёт `float`.
- `input()` всегда возвращает **строку**. Для чисел оборачивай в `int()` или `float()`.
- Преобразование: `int()`, `float()`, `str()`.
