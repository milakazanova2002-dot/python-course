# Урок 4. Условия if / elif / else

**Цель урока:** научить программу принимать решения: выполнять разные действия в зависимости от данных.

**К концу урока ты умеешь:**
- сравнивать значения и получать `True` или `False`;
- писать условия `if`, `else` и `elif`;
- правильно оформлять отступы;
- соединять условия с помощью `and`, `or`, `not`;
- решать задачи, где программа выбирает один из нескольких вариантов.

---

## 1. Зачем нужны условия

До сих пор наши программы выполнялись **строго по порядку**, строчка за строчкой, и всегда делали одно и то же. Но в жизни мы постоянно выбираем: *«Если на улице дождь, возьму зонт. Иначе пойду без него»*.

Программы тоже умеют выбирать. Для этого есть **условные конструкции**: программа проверяет условие и в зависимости от результата выполняет разный код.

```
Условие верно?
   ├── Да  → выполнить один код
   └── Нет → выполнить другой код
```

---

## 2. Сравнения и тип bool

Условие это вопрос, на который можно ответить только **«да» или «нет»**. В Python «да» это `True`, а «нет» это `False`. Это значения типа `bool`, с которым мы познакомились во втором уроке.

Чтобы задать такой вопрос, используются **операторы сравнения**:

| Оператор | Значение | Пример | Результат |
|---|---|---|---|
| `==` | равно | `5 == 5` | `True` |
| `!=` | не равно | `5 != 3` | `True` |
| `>` | больше | `5 > 7` | `False` |
| `<` | меньше | `5 < 7` | `True` |
| `>=` | больше или равно | `5 >= 5` | `True` |
| `<=` | меньше или равно | `6 <= 5` | `False` |

Результат сравнения можно вывести или сохранить в переменную:

```python
age = 15
print(age >= 18)
is_adult = age >= 18
print(is_adult)
```

```
False
False
```

### Самая частая ошибка: = и ==

Это **два разных знака**:

- `=` кладёт значение в переменную: `age = 15`;
- `==` **сравнивает** два значения и отвечает `True` или `False`: `age == 15`.

### Сравнение строк

Строки тоже можно сравнивать на равенство:

```python
print("Аня" == "Аня")
print("Аня" == "аня")
```

```
True
False
```

Большая и маленькая буквы считаются **разными**. Поэтому, чтобы не зависеть от регистра, ответ пользователя часто приводят к нижнему регистру: `answer.lower()`.

Оператор `in` из прошлого урока тоже даёт `True` или `False`:

```python
print("th" in "Python")
```

```
True
```

### Сравнивать можно только похожие типы

Число с числом, строку со строкой. Сравнение `str` с `int` через `>` вызовет ошибку:

```python
age = input("Возраст: ")
print(age > 18)
```

```
TypeError: '>' not supported between instances of 'str' and 'int'
```

Причина знакома: `input()` возвращает строку. Нужно записать `age = int(input("Возраст: "))`.

## 3. Оператор if

**`if`** («если») выполняет код только тогда, когда условие истинно.

```python
age = int(input("Сколько тебе лет? "))

if age >= 18:
    print("Ты совершеннолетний")

print("Конец программы")
```

Если ввести `20`:

```
Ты совершеннолетний
Конец программы
```

Если ввести `15`:

```
Конец программы
```

Как устроена запись:

```
if  age >= 18  :
 ↑      ↑      ↑
слово  условие двоеточие

    print(...)
    ↑
  отступ
```

### Двоеточие и отступ

1. После условия **обязательно ставится двоеточие** `:`.
2. Код, который выполняется при истинном условии, пишется **с отступом**: это 4 пробела или одно нажатие клавиши **Tab**. VS Code сам ставит отступ после двоеточия, когда ты нажимаешь **Enter**.
3. Строка **без отступа** (как `print("Конец программы")` выше) уже не относится к `if` и выполняется всегда.

Отступ в Python это не украшение, а часть языка. Именно по нему Python понимает, какие строки «внутри» условия. Если отступ неверный, получится ошибка `IndentationError`.

### Несколько строк внутри if

Все строки с одинаковым отступом относятся к одному `if`:

```python
number = int(input("Введи число: "))

if number > 0:
    print("Число положительное")
    print("Это хорошо")
    print(f"Его квадрат: {number ** 2}")
```

## 4. Оператор else

**`else`** («иначе») выполняется, когда условие в `if` оказалось ложным.

```python
age = int(input("Сколько тебе лет? "))

if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

```
Сколько тебе лет? 15
Доступ запрещён
```

Правила:

- `else` пишется **на том же уровне**, что и `if` (без отступа относительно него);
- после `else` тоже ставится двоеточие;
- у `else` нет условия, он срабатывает, когда все условия выше были ложны;
- выполнится **одна** из двух веток: либо `if`, либо `else`.

### Пример: чётное или нечётное

Число чётное, если остаток от деления на 2 равен нулю. Вспоминаем `%` из урока 2:

```python
n = int(input("Введи число: "))

if n % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")
```

## 5. Оператор elif

Иногда вариантов больше двух. Для этого есть **`elif`** (сокращение от *else if*: «а если ещё...»).

```python
temperature = int(input("Температура на улице: "))

if temperature < 0:
    print("Холодно, надень куртку")
elif temperature < 15:
    print("Прохладно, надень кофту")
elif temperature < 25:
    print("Тепло, можно идти в футболке")
else:
    print("Жарко, пей больше воды")
```

### Как это работает

Python проверяет условия **сверху вниз** и останавливается на первом истинном:

1. Если `temperature < 0` верно, выполняется первая ветка, **остальные не проверяются**.
2. Если нет, проверяется `temperature < 15`. Если верно, выполняется вторая ветка.
3. Если нет, проверяется следующее условие.
4. Если все условия ложны, выполняется `else`.

Поэтому для температуры `10` сработает именно вторая ветка («Прохладно»), хотя `10 < 25` тоже верно: до третьей ветки дело просто не дойдёт.

### Порядок важен

Сравни два варианта для оценки по баллам:

```python
score = 95

# Верно
if score >= 90:
    print("Отлично")
elif score >= 60:
    print("Хорошо")
```

```python
score = 95

# Неверно!
if score >= 60:
    print("Хорошо")
elif score >= 90:
    print("Отлично")
```

Во втором случае для `95` выведется «Хорошо»: первое условие уже истинно, до `elif` Python не доходит. Условия нужно располагать так, чтобы **более строгие проверялись раньше**.

### Структура целиком

```python
if условие1:
    ...
elif условие2:
    ...
elif условие3:
    ...
else:
    ...
```

- `if` бывает только один и всегда первый;
- `elif` может быть сколько угодно, а может не быть совсем;
- `else` бывает один, всегда последний, и его можно не писать.

## 6. Логические операторы: and, or, not

Иногда нужно проверить сразу несколько условий. Их соединяют словами:

| Оператор | Значение | Результат |
|---|---|---|
| `and` | «и» | `True`, только если **оба** условия истинны |
| `or` | «или» | `True`, если **хотя бы одно** условие истинно |
| `not` | «не» | меняет `True` на `False` и наоборот |

### and («и»)

```python
age = int(input("Возраст: "))

if age >= 12 and age <= 17:
    print("Подросток")
```

Условие истинно, только если возраст не меньше 12 **и** не больше 17.

В Python такую проверку можно записать короче, как в математике:

```python
if 12 <= age <= 17:
    print("Подросток")
```

### or («или»)

```python
day = input("День недели: ")

if day == "суббота" or day == "воскресенье":
    print("Выходной!")
else:
    print("Рабочий день")
```

### not («не»)

```python
raining = True

if not raining:
    print("Можно идти без зонта")
```

### Таблицы истинности

| A | B | A and B | A or B |
|---|---|---|---|
| `True` | `True` | `True` | `True` |
| `True` | `False` | `False` | `True` |
| `False` | `True` | `False` | `True` |
| `False` | `False` | `False` | `False` |

### Типичная ловушка

Нельзя писать так:

```python
if day == "суббота" or "воскресенье":    # неверно!
```

Нужно повторять сравнение целиком:

```python
if day == "суббота" or day == "воскресенье":    # верно
```

## 7. Вложенные условия

Внутри `if` может быть ещё один `if`. Он пишется с **дополнительным отступом**.

```python
age = int(input("Возраст: "))

if age >= 18:
    has_ticket = input("Есть билет? (да/нет) ")
    if has_ticket == "да":
        print("Проходи")
    else:
        print("Сначала купи билет")
else:
    print("Вход только с 18 лет")
```

Каждый уровень вложенности это новый отступ. Если можно обойтись одним условием с `and`, лучше так и сделать: код короче и читается проще.

## 8. Полезные приёмы

**Чётность:** `n % 2 == 0` значит, что число чётное.

**Делимость:** `n % 5 == 0` значит, что `n` делится на 5 без остатка.

**Регистр:** чтобы ответ «Да», «да» и «ДА» считались одинаково, приводи ввод к нижнему регистру:

```python
answer = input("Продолжить? (да/нет) ").lower()

if answer == "да":
    print("Продолжаем")
else:
    print("Выходим")
```

**Диапазон:** `18 <= age < 65` проверяет, что значение лежит в промежутке.

## 9. Частые ошибки

| Ошибка | Что значит | Как исправить |
|---|---|---|
| `SyntaxError: invalid syntax` у строки с `if` | Написано `=` вместо `==` или забыто двоеточие | В условии используй `==`, в конце строки ставь `:` |
| `IndentationError: expected an indented block` | Под `if` нет отступа | Сдвинь строки внутри `if` на 4 пробела (клавиша Tab) |
| `IndentationError: unindent does not match` | Отступы в разных строках разной ширины | Используй везде одинаковый отступ |
| `TypeError: '>' not supported between instances of 'str' and 'int'` | Сравниваешь строку с числом | Преврати ввод в число: `int(input(...))` |
| `SyntaxError` у `elif` или `else` | `elif` или `else` без `if`, либо с неверным отступом | `elif` и `else` пишутся на том же уровне, что и `if` |
| Программа выводит не то, что ожидалось | Условия стоят в неверном порядке | Проверь, что строгие условия идут раньше |

## Итоги урока

- Условие это выражение, результат которого `True` или `False`.
- Операторы сравнения: `==`, `!=`, `>`, `<`, `>=`, `<=`. Помни: `=` кладёт значение, `==` сравнивает.
- `if` проверяет условие, `elif` проверяет следующие, `else` срабатывает, если ни одно не подошло. Выполняется **только одна ветка**.
- После условия ставится `:`, а код внутри пишется **с отступом**.
- `and` («и»), `or` («или»), `not` («не») соединяют условия.
- Ввод превращай в число перед сравнением: `int(input(...))`.
