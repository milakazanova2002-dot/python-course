# Урок 1. Знакомство с Python и Visual Studio Code

**Цель урока:** установить Python и VS Code, написать и запустить первую программу.

**К концу урока ты умеешь:**
- объяснить, что такое программа и зачем нужен Python;
- создать файл `.py` в VS Code;
- запустить программу двумя способами;
- выводить текст и числа с помощью `print()`;
- пользоваться комментариями и горячими клавишами.

---

## 1. Что такое программа

**Программа** это набор инструкций для компьютера. Компьютер выполняет их строго по порядку, сверху вниз, и делает ровно то, что написано. Он не догадывается, что ты имел в виду.

**Язык программирования** это способ записать такие инструкции так, чтобы их поняли и человек, и компьютер. Языков много: Python, JavaScript, C++ и другие.

**Почему Python:**
- простой и читаемый, код похож на обычный английский;
- на нём пишут сайты, игры, ботов, анализ данных, нейросети;
- хорош для первого языка.

**Как работает запуск.** Ты пишешь код в текстовом файле. Программа **Python** (её называют *интерпретатор*) читает этот файл строчка за строчкой и выполняет команды.

## 2. Установка Python

1. Зайди на сайт **python.org** → раздел **Downloads** → скачай последнюю версию.
2. Запусти установщик.
3. **Важно!** В первом окне внизу поставь галочку **Add python.exe to PATH** и только потом нажимай **Install Now**.

> Эта галочка нужна, чтобы компьютер знал, где лежит Python, и находил его по команде `python`. Если её забыть, дальше ничего не запустится. Тогда установщик нужно запустить заново и поставить галочку.

4. Дождись окончания установки.

**Проверка:** открой командную строку (Windows: клавиша `Win`, набери `cmd`, Enter) и напиши:

```
python --version
```

Должна появиться версия, например `Python 3.13.0`. Если пишет, что команда не найдена, значит галочка PATH не была поставлена.

> На macOS и Linux команда обычно называется `python3`.

---

## 3. Установка Visual Studio Code

**VS Code** это редактор кода. В нём ты будешь писать и запускать программы. Он бесплатный.

1. Зайди на **code.visualstudio.com** → **Download** → скачай версию для своей системы.
2. Установи с настройками по умолчанию.
3. Запусти VS Code.

### Расширение Python

Само по себе VS Code не умеет работать с Python, ему нужно расширение.

1. Слева нажми значок **Extensions** (квадратики) или **Ctrl + Shift + X**.
2. В поиске напиши `Python`.
3. Выбери расширение **Python** от **Microsoft** и нажми **Install**.

---

## 4. Первый проект

1. Создай на компьютере папку для курса, например `python-course`. Названия лучше писать латиницей, без пробелов.
2. В VS Code: **File → Open Folder** → выбери эту папку.
3. Если VS Code спросит, доверяешь ли ты авторам файлов в этой папке (**Trust**), нажми **«Yes, I trust the authors»**. Без этого разрешения код может не запускаться.
4. В левой панели (Explorer) наведи на название папки и нажми значок **New File**.
5. Назови файл `hello.py`. Расширение `.py` обязательно: по нему компьютер понимает, что это файл Python.

## 5. Первая программа

В файле `hello.py` напиши:

```python
print("Привет, мир!")
```

**Разберём:**

```
print("Привет, мир!")
  ↑         ↑
команда   что вывести
```

- `print` это **функция**: готовая команда, которая выводит что-то на экран;
- в круглых скобках мы пишем, **что** вывести;
- текст всегда пишется в **кавычках**.

Сохрани файл: **Ctrl + S**.

## Автосохранение

### Зачем это нужно

Python запускает **сохранённую** версию файла. Если ты изменил код, но не нажал **Ctrl + S**, то при запуске командой `python hello.py` выполнится старая версия. Ты видишь на экране новый код, а программа работает по-старому, и кажется, что «ничего не меняется» или «код сломался сам». Это одна из самых частых причин непонятных ошибок у начинающих.

**Как заметить, что файл не сохранён:** на вкладке с названием файла вверху появляется **белая точка** вместо крестика. Нет точки, значит всё сохранено.

Автосохранение решает проблему: VS Code сам сохраняет файл, и про **Ctrl + S** можно не помнить. Поэтому включим его один раз сразу.

### Как включить

**Самый быстрый способ:**

1. В верхнем меню выбери **File** (Файл).
2. Найди пункт **Auto Save** (Автосохранение) и нажми на него, чтобы появилась галочка.

**Через настройки** (если в меню нет такого пункта):

1. Открой настройки: **Ctrl + ,** (запятая) или **File → Preferences → Settings**. На macOS: **Cmd + ,**.
2. В строке поиска вверху напиши `Auto Save`.
3. В пункте **Files: Auto Save** выбери значение **afterDelay**.
4. Чуть ниже в пункте **Files: Auto Save Delay** можно оставить `1000`. Это значит, что файл сохраняется через 1 секунду после того, как ты перестал печатать.

### Что означают варианты

| Значение | Что делает |
|---|---|
| `off` | Автосохранение выключено (так обычно стоит по умолчанию) |
| `afterDelay` | Сохраняет через секунду после последнего изменения. **Выбираем его** |
| `onFocusChange` | Сохраняет, когда ты переключаешься на другое окно или файл |
| `onWindowChange` | Сохраняет, когда ты уходишь из окна VS Code |

### Проверка

Измени что-нибудь в файле, подожди секунду и посмотри на вкладку: белая точка должна исчезнуть сама, без нажатия **Ctrl + S**.

> Привычку нажимать **Ctrl + S** всё равно полезно сохранить. В других программах автосохранения может не быть.

## 6. Как запустить программу

### Способ 1. Кнопка ▶

В правом верхнем углу окна нажми **▶ (Run Python File)**. Внизу откроется терминал с результатом:

```
Привет, мир!
```

**Если кнопки нет:**

1. Проверь, что файл называется именно `hello.py`, а не `hello.py.txt`.
2. Проверь, что установлено расширение **Python** от Microsoft.
3. Нажми **Ctrl + `** (клавиша с буквой Ё, слева от единицы), чтобы открыть терминал. Если VS Code просит разрешение, нажми **«Yes, I trust the authors»** / **«Разрешить»**.
4. Нажми **Ctrl + Shift + P**, введи `Python: Select Interpreter` и выбери установленный Python.

### Способ 2. Через терминал

Кнопка удобна, но программисты чаще запускают код командой. Поэтому учимся этому сразу.

1. Открой терминал: **Ctrl + `**
2. Убедись, что ты в папке с файлом (путь виден слева от курсора).
3. Напиши:

```
python hello.py
```

и нажми **Enter**.

> macOS и Linux: `python3 hello.py`. Windows, если `python` не работает: `py hello.py`.

### Почему мы пишем `python`, а не просто `hello.py`

```
python   hello.py
  ↑         ↑
 кто       что
запускает  запускать
```

- `hello.py` это просто **текстовый файл** с твоим кодом. Сам он ничего не умеет, как рецепт, который сам себя не приготовит.
- `python` это **интерпретатор**, программа, которая умеет читать код и выполнять его. Она как повар, который читает рецепт.

Командой `python hello.py` ты говоришь компьютеру: «Запусти программу `python` и дай ей файл `hello.py`». Если написать только `hello.py`, компьютер не поймёт, что делать с файлом.

### Если что-то пошло не так

| Что видишь | Что делать |
|---|---|
| `python не является внутренней или внешней командой` | Python установлен без галочки **Add Python to PATH**. Переустанови и поставь галочку |
| `can't open file ... No such file` | Ты не в той папке или опечатка в имени файла. Проверь имя и путь |
| Нет кнопки ▶ | Расширение Python, разрешение (Trust), интерпретатор. Пункты выше |

## 7. Функция print()

### Текст и числа

```python
print("Меня зовут Аня")
print(25)
print(3 + 4)
```

Результат:

```
Меня зовут Аня
25
7
```

- Текст пишем **в кавычках**: `"..."` или `'...'`.
- Числа пишем **без кавычек**. Python сам может их считать: `3 + 4` выведет `7`.
- Сравни: `print(3 + 4)` выведет `7`, а `print("3 + 4")` выведет `3 + 4`. В кавычках это просто текст.

### Несколько значений в одном print

Значения разделяются запятой, а при выводе между ними ставится пробел:

```python
print("Мне", 14, "лет")
```

```
Мне 14 лет
```

### Пустая строка

```python
print("Первая строка")
print()
print("Третья строка")
```

`print()` без ничего внутри выводит пустую строку.

### Частые ошибки

| Код | Что не так |
|---|---|
| `Print("Привет")` | `print` пишется с маленькой буквы |
| `print("Привет)` | не закрыта кавычка |
| `print("Привет"` | не закрыта скобка |
| `print(Привет)` | текст без кавычек |

Когда Python не понимает код, он показывает **ошибку**, например `SyntaxError`. Это нормально, ошибки бывают у всех. Внимательно прочитай сообщение: оно подсказывает, в какой строке проблема.

## 8. Комментарии

**Комментарий** это строка, которую Python пропускает. Она начинается с `#`.

```python
# Это комментарий, Python его не выполняет
print("Привет")  # комментарий можно писать и после кода
```

Комментарии нужны, чтобы пояснять код и временно отключать ненужные строки.

---

## 9. Горячие клавиши

Горячие клавиши экономят время: пара нажатий вместо поиска кнопки в меню.

### Комментирование: Ctrl + /

1. Поставь курсор на строку или выдели несколько строк.
2. Нажми **Ctrl + /**.
3. В начале строк появится `#`, и Python перестанет их выполнять.
4. Чтобы вернуть, выдели строки и снова нажми **Ctrl + /**.

Было:

```python
print("Привет")
print("Это сообщение пока не нужно")
print("Пока")
```

Выделили вторую строку, нажали **Ctrl + /**:

```python
print("Привет")
# print("Это сообщение пока не нужно")
print("Пока")
```

Выведется только «Привет» и «Пока».

> Когда код не работает, часть строк можно временно «выключить» и посмотреть, что изменится. Это быстрее, чем стирать и писать заново.
>
> Если сочетание не срабатывает, проверь раскладку: переключись на английскую.

### Перенос длинных строк: Alt + Z

Если строка длиннее окна, она уходит за правый край. Нажми **Alt + Z**, и длинные строки перенесутся на следующую строчку прямо на экране, весь код будет виден на странице. Сам код не меняется. Чтобы выключить, нажми **Alt + Z** ещё раз.

### Таблица клавиш

| Действие | Windows / Linux | macOS |
|---|---|---|
| Закомментировать / раскомментировать | Ctrl + / | Cmd + / |
| Перенос строк | Alt + Z | Option + Z |
| Сохранить файл | Ctrl + S | Cmd + S |
| Отменить действие | Ctrl + Z | Cmd + Z |
| Открыть / закрыть терминал | Ctrl + ` | Ctrl + ` |

## Итоги урока

- Программа это инструкции, которые компьютер выполняет по порядку.

- `print()` выводит на экран текст (в кавычках) и числа.
